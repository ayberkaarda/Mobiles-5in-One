## Item 1 and 2 commands (local evidence)

Run from the Git repository root (the directory that holds `.gitleaks.toml`).

Full-history scan (item 2), as the CI job runs it:

```sh
gitleaks git --no-banner --redact --log-opts="--all" .
```

Staged changes, as the pre-commit hook runs it:

```sh
gitleaks git --pre-commit --staged --redact --no-banner .
```

Working tree without Git (item 1). `next build` output under `apps/web/.next/` contains generated
preview and encryption keys that gitleaks reports as `generic-api-key`; the directory is ignored by
Git; `.gitleaks.toml` allow-lists `.next/` and `node_modules/`, so the scan is clean after a build:

```sh
gitleaks dir --no-banner --redact -c .gitleaks.toml kadro
```

Proof that the rules catch real-format secrets, without committing anything: the command below
writes freshly generated look-alike secrets (an AWS key id plus secret, a Stripe-style live key and
an RSA private key) into a temporary directory outside the repository, scans it, and deletes it.
The scan must exit with 1 and report `aws-access-token`, `stripe-access-token` and `private-key`.

```sh
dir=$(mktemp -d)
node -e '
const c = require("node:crypto"), fs = require("node:fs"), p = require("node:path");
const a = "ABCDEFGHIJKLMNOPQRSTUVWXYZ234567", d = process.argv[1];
const id = ["AK", "IA", [...c.randomBytes(16)].map((b) => a[b % 32]).join("")].join("");
const secret = c.randomBytes(30).toString("base64").replace(/[+/=]/g, "x").slice(0, 40);
fs.writeFileSync(p.join(d, "aws.ini"), `[default]\naws_access_key_id = ${id}\naws_secret_access_key = ${secret}\n`);
fs.writeFileSync(p.join(d, "stripe.ts"), `export const stripeKey = "${["s", "k_", "live_", c.randomBytes(16).toString("hex")].join("")}";\n`);
fs.writeFileSync(p.join(d, "server.pem"), c.generateKeyPairSync("rsa", { modulusLength: 2048,
  privateKeyEncoding: { type: "pkcs8", format: "pem" }, publicKeyEncoding: { type: "spki", format: "pem" } }).privateKey);
' "$dir"
gitleaks dir --no-banner --redact -v -c .gitleaks.toml "$dir"; echo "exit=$?"
rm -rf "$dir"
```

Result on 2026-10-01 (gitleaks 8.30.1): 4 findings (`stripe-access-token`, `generic-api-key`,
`aws-access-token`, `private-key`), exit 1; temporary directory removed. Full history: 37 commits,
no leaks. Working tree: no findings (build output allow-listed).
