# SEO and GEO checklist

The checklist that the product spec asks for in Phase 6 (section 7, the Phase 4 gate "Lighthouse at least 90 performance, SEO and accessibility on 5 sample pages; JSON-LD validates", and the Phase 6 item "SEO/GEO checklist"). One row per requirement. Every evidence entry was checked against the code on `main` at `bf733f5`; paths are relative to `kadro/apps/web/` unless they start with `docs/`.

Status values:

- **done**: implemented and covered by a test or a file you can read.
- **partial**: implemented in part; the gap is named.
- **not done**: absent; the reason is named (an ADR scope decision where one exists).
- **needs real domain**: the code is in place, but the proof cannot be produced without a deployed https origin or store accounts.

Kadro is a portfolio project. Rows that say "done" mean "done for the portfolio build", not "proven in production". Related pages: [`../web/seo-and-geo.md`](../web/seo-and-geo.md) (how it works), [`geo-facts.md`](geo-facts.md) (brand facts), [`../web/pages.md`](../web/pages.md).
