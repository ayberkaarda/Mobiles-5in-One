## Update rules

1. A status moves only in the same change that adds the proof, and the Evidence cell names the file
   or test and the command that was run.
2. A claim of `done` needs a recorded run of the cited test or command; a skipped or not-run test
   is reported as such. A run on a delivering branch is named as such.
