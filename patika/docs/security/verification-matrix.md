# Verification matrix (final, phase 6)

The 23-item checklist from the specification (§6), adapted from the iOS wording to what this repository builds: a .NET MAUI Android app, an ASP.NET Core API, Razor Pages web and admin, a .NET Worker, PostgreSQL with PostGIS and S3-compatible storage. Status as of 2026-10-26, branch `feat/patika-p6`.

- **done**: the control is implemented and the named evidence was executed (tests in `dotnet test Patika.slnx`, CI jobs in `.github/workflows/patika-ci.yml`, scans in [`scans/`](scans/)).
- **partial**: the code path exists and is tested, but part of the proof needs a real-world system this portfolio project does not have (a domain with TLS, a Play Console app, cloud buckets). What is simulated is named in the row.
- **not applicable**: none. Every iOS item has an Android or server equivalent (ATS becomes the network security config, Keychain becomes `SecureStorage`, IPA becomes APK, App Store becomes Google Play).

Summary: **19 done, 4 partial, 0 not applicable** (partial: 10, 17, 20, 23).

Test projects: `Patika.Api.Tests` (Api), `Patika.SecurityTests` (Security), `Patika.Web.Tests` (Web), `Patika.Worker.Tests` (Worker), `Patika.App.Tests` (App), `Patika.Domain.Tests` (Domain). Last full run: 1,456 passed and 2 skipped; the 2 skipped `AdoptionPersistenceTests` were run separately with `PATIKA_TEST_DB` against a migrated PostGIS database and passed.
