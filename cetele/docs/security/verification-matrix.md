## Update rules

1. A status moves up only in the same change that adds the proof, and the Evidence cell names the
   file or test and the command that was run.
2. A claim of `done` needs a recorded run of the cited test or command on the commit it describes; a
   skipped or not-run test is reported as such.
3. An item whose proof needs an unreachable external system stays `partial` and keeps its
   `not exercised: <reason>` text.
4. Counts are recomputed from the table whenever a status changes.
